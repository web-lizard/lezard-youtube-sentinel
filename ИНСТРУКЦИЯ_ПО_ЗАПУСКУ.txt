LIZARD SENTINEL — ИНСТРУКЦИЯ ПО ЗАПУСКУ
=========================================

Требования:
- Node.js 20 или новее;
- npm 10 или новее;
- Firefox 140 или новее.

1. Установка зависимостей
------------------------

Откройте PowerShell в каталоге проекта и выполните:

  npm install

2. Сборка и проверка
-------------------

  npm run build

Готовое распакованное расширение появится в каталоге:

  dist

3. Загрузка расширения в Firefox
--------------------------------

1) Откройте в Firefox адрес:

   about:debugging#/runtime/this-firefox

2) Нажмите «Load Temporary Add-on…» / «Загрузить временное дополнение…».

3) Выберите файл:

   dist/manifest.json

4) Откройте видео YouTube с комментариями или страницу комментариев
   YouTube Studio.

5) Нажмите значок Lizard Sentinel и выберите «Сканировать сейчас».

4. Запуск без YouTube и API-ключа
--------------------------------

В popup расширения нажмите:

  «Запустить demo на mock-данных»

Расширение обработает тестовый набор комментариев и покажет статистику,
ответы и безопасные Shield-summary.

5. Настройка DeepSeek / OpenAI-compatible API
----------------------------------------------

1) Откройте «Настройки» в popup.
2) Выберите provider «OpenAI-compatible / DeepSeek».
3) Укажите Base URL, Model и API key.
4) Нажмите «Проверить соединение».
5) Нажмите «Сохранить настройки».

По умолчанию используется локальный Mock provider.

6. Безопасность реальных ответов
--------------------------------

По умолчанию включён DRY RUN. В этом режиме ответы создаются, но не
отправляются на YouTube.

Реальная публикация разрешается только после ручного включения настройки:

  Allow real replies

Сначала обязательно проверьте mock-режим и dry-run на реальной странице.

7. Режим разработки
-------------------

  npm run dev

После изменения кода нажмите Reload у расширения на странице about:debugging.

8. Тесты и ZIP-пакет
--------------------

  npm run check
  npm run package

ZIP-пакет будет создан в каталоге artifacts.
